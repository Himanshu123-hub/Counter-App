# 🔢 JavaScript Counter App

## 📌 Project Description

The JavaScript Counter App is a simple and interactive web application built using HTML, CSS, and Vanilla JavaScript. It allows users to increase, decrease, and reset a numerical counter with the help of button clicks.

This project is designed to practice JavaScript DOM manipulation and understand how JavaScript interacts with HTML elements dynamically.

## ✨ Features

- ➕ **Increase Counter:** Increases the counter value by 1.
- ➖ **Decrease Counter:** Decreases the counter value by 1.
- 🔄 **Reset Counter:** Resets the counter value back to 0.
- ⚡ **Real-Time Updates:** Updates the displayed number instantly without refreshing the page.
- 🎨 **Simple UI:** Clean and user-friendly interface.
- 📱 **Responsive Design:** Basic layout suitable for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the application.
- **CSS3** – For styling and designing the user interface.
- **JavaScript (Vanilla JS)** – For implementing counter functionality and DOM manipulation.

## 📚 JavaScript Concepts Practiced

Through this project, I practiced the following JavaScript concepts:

- DOM Selection using `document.querySelector()`
- Variables and variable updates
- `addEventListener()`
- Click Events
- DOM Manipulation
- `textContent`
- Functions and conditional logic (if used)
